# TP3 - Perceptrons

> [!NOTE]  
> Los comandos son relativos a la carpeta de este archivo (`/tp3`)

## Instalación

```bash
uv sync
```

## Uso

```bash
tp3 -c res/config/config_all_digits.json -o res/output.json
tail -n10 res/output.json
```

Hay ejemplos de configuraciones en `res/config/`.
El json está tipado con un schema para conocer los parámetros válidos.

Datasets disponibles en `res/datasets/`
